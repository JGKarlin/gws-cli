gws-cli

A personal OAuth client for the open-source Google Workspace CLI.

gws-cli is the Google Cloud OAuth client I use to run gws, an open-source command-line tool for Google Workspace, against my own Google account. It lets me work with my Drive, Docs, Sheets, Slides, Calendar and Gmail from the terminal.

It is not a public service. It has one user, me, and nobody else is invited to sign in with it. There is no server: commands run on my computer and talk directly to Google's APIs.

How it handles data is described in the privacy policy.
