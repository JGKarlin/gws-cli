Privacy policy

gws-cli · last updated 12 October 2026

gws-cli is an OAuth client I, Jason Karlin, operate for my own use with the open-source Google Workspace CLI. This page explains what it accesses and where that data goes.

Who it is for

Only me. It is not offered to anyone else, and nobody else is invited to sign in with it.

What it accesses

When I run a command, gws-cli reads or changes data in my Google account in the services I have granted: Google Drive, Docs, Sheets, Slides, Calendar and Gmail. It also receives my name, email address and profile picture to identify the signed-in account. It does nothing when I am not running a command.

Where the data goes

  • Requests go directly from my computer to Google's APIs. gws-cli has no server of its own, so no data is received, stored or logged anywhere else by this app.
  • Sign-in credentials are stored encrypted on my computer.
  • I sometimes run gws through an AI assistant (Claude Code). When I do, command output is sent to that assistant's provider as part of my own session, under that provider's terms.

Sharing

Data is never sold, shared with third parties, used for advertising, or collected for analytics.

gws-cli's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from your Google Account's third-party access page. Revoking it stops gws-cli working immediately.

Contact

Questions can go to me through my GitHub profile.
